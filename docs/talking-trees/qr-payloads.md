# Talking Tree QR code payloads

Each Talking Tree sign carries a QR code whose text is `wca-tree:` followed by the tree ID. Every entry below is NEEDS VERIFICATION until the client confirms the species and the location of each tree.

| Tree ID | Species (English) | QR payload text |
| --- | --- | --- |
| yellow-birch-1 | Yellow birch | `wca-tree:yellow-birch-1` |
| red-spruce-1 | Red spruce | `wca-tree:red-spruce-1` |
| red-maple-1 | Red maple | `wca-tree:red-maple-1` |
| white-pine-1 | Eastern white pine | `wca-tree:white-pine-1` |

A web address of the form `https://<site address>/trees/<tree ID>` also works once the site address is final.
