# Image audio descriptions

Prerecorded MP3 descriptions for pictures, one file per picture and language.

Naming convention: `<imageId>_<lang>.mp3` (for example `about_en.mp3`, `about_fr.mp3`).

`docs/audio/image-audio-recording-script.md`. Languages planned are listed in
